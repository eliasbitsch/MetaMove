# Bari kitting cell - Blender sources

The FBX files under `unity-quest/Assets/MetaMove/Models/Bari/` are generated by these
scripts in Blender 5.1. Nothing is modelled by hand.

| Script | Exports |
|---|---|
| `bari_assets.py` | helpers (`mat`, `box`, `join`, `cut`, `export`) plus gears, KLT, kit, table, signal tower, trolley |
| `flowrack.py` | flow rack, compact robot table, lighter gears |
| `factory.py` | floor island, broken wall, conveyor, steel beam with pendant lamp, portal mask |

`flowrack.py` and `factory.py` expect the helpers of `bari_assets.py` in front of them.
Run them in a live Blender with the MCP add-on on port 9877:

```
cat bari_assets.py factory.py > /tmp/send.py && python bsend.py /tmp/send.py
```

Coordinates are written in the Unity cell frame; Blender FBX lands in Unity as
(x, y, z) -> (-x, z, -y). Triangulate concave caps after any boolean, never before, and
do not run booleans on joined, overlapping boxes: the exact solver returns an empty mesh.
